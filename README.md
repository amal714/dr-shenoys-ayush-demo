## ✨ Key Features

### 1. The 5 Pillars of AYUSH Care (Weekly Rotation)
* **Monday:** Ayurveda (Tridosha balance, pulse diagnosis & rejuvenation)
* **Tuesday:** Yoga & Naturopathy (Breath alignment & drugless therapies)
* **Wednesday:** Unani (Humoral equilibrium & regimenal care)
* **Thursday:** Siddha (Kayakalpa, longevity & Varmam therapies)
* **Friday:** **Heiki** (Bio-energetic resonance & subtle vibrational therapeutics — strictly replacing Homeo per clinic standards)
* **Saturday:** General AYUSH Review & Follow-up Clinic

### 2. Parallel Psychological Counselling Track (Mon–Sat)
* Runs concurrently in a separate consultation chamber led by dedicated clinical psychologist Dr. Ananya Varma for cognitive, emotional, and stress management.

### 3. Precision 30-Minute OPD Slot Engine
* **Hours:** 9:00 AM to 7:00 PM, Monday through Saturday (Sundays closed).
* **Lunch Break:** Mandatory sanitization & lunch recess from **01:00 PM to 02:00 PM** (non-bookable).
* **18 Bookable Slots/Day:** 8 morning slots + 10 afternoon/evening slots.

### 4. Frictionless Booking & Identity Verification
* **Photo ID Upload:** Optional document upload (Aadhaar / Voter ID / Driving License) with client-side preview.
* **Instant Mobile OTP Mode:** Alternative quick verification to prevent drop-offs.
* **Digital OPD Pass:** Token number generation (`AYU-###` / `COU-###`), downloadable/printable slip, and 1-click WhatsApp appointment sharing.

### 5. High-Security Reception & Admin Desk
* **Passcode Protected:** Restricted portal for Dr. Shenoy and front-desk reception (Default PIN: `2026` or `shenoy2026`).
* **Telephone / Offline Walk-In Quick Booking:** Rapid entry form for phone callers (`062826 32035`) and walk-in patients.
* **Emergency Slot Blocker:** 1-tap block/unblock during urgent hospital visits or emergency procedures.
* **Patient Flow Management:** Real-time status toggles (`Confirmed` → `Arrived at OPD` → `In Consultation` → `Completed`).
* **Print OPD Sheet:** Daily queue sheet printable for the doctor's consultation desk.

### 6. Live OPD Waiting Room Monitor
* Real-time waiting room token board displaying active and upcoming tokens for Chamber 1 (AYUSH) and Chamber 2 (Counselling) to prevent waiting room crowding.

## 🚀 Getting Started

### Prerequisites
* Node.js 18+ (Node 24 LTS verified)
* npm / yarn / pnpm

### Installation
```bash
git clone https://github.com/amal714/dr-shenoys-ayush-demo.git
cd dr-shenoys-ayush-demo
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
